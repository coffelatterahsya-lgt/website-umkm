# Website Bengkel Kita

1. Deskripsi Project
Website layanan bengkel motor merupakan website yang dibuat untuk memberikan informasi mengenai layanan perawatan dan perbaikan motor. Website ini membantu pelanggan mengetahui berbagai layanan yang tersedia dan informasi lebih lanjut terkait motor. Selain itu, website ini menyediakan akses untuk melakukan pemesanan atau konsultasi melalui WhatsApp.

3. Tujuan Project
Project ini bertujuan untuk mengembangkan website sebagai media informasi bagi pemilik usaha agar informasi usaha dapat diakses dengan lebih mudah oleh customer melalui internet.

4. Fitur dan Section Website
- **Home:** Halaman utama website.
- **About:** Berisi informasi mengenai usaha bengkel tersebut.
- **Contact:** Menyediakan informasi kontak untuk menghubungi pihak pemilik bengkel.
- **Layanan:** Menyediakan informasi berupa layanan yang tersedia dan ketentuan untuk booking.

5. Teknologi yang Digunakan
- HTML untuk menyusun struktur halaman website.
- CSS untuk mengatur tampilan dan tata letak website.
- JavaScript untuk memperbaiki error pada bagian contact..

6. Cara Menjalankan Website Secara Lokal
- Download repository ini dari GitHub.
- Buka folder project di Visual Studio Code.
- Buka file `index.html` menggunakan browser atau ekstensi Live Server.
- Website dapat diakses secara lokal melalui browser.
